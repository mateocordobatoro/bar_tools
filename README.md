# BarThings

MVP stack: Next.js + TypeScript + Supabase + Vercel.

## MVP
- PIN login
- Roles: management / bartender
- Batch requests
- Batch runs
- Partial steps
- Blocked reasons
- Quantities
- Ready status

## Local setup
```bash
npm install
cp .env.example .env.local
npm run dev
```
